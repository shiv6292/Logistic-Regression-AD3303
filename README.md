## 1. Aim
To implement Logistic Regression for binary classification and evaluate the model using different classification performance metrics.

## 2. Dataset
**Dataset Name:** Breast Cancer Wisconsin Dataset

**Source:** Scikit-learn built-in dataset (`sklearn.datasets.load_breast_cancer`).

The dataset contains features computed from digitized images of breast mass samples. The objective is to classify the samples into two categories:
- **Benign (0)**
- **Malignant (1)**

## 3. Tools and Technologies
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## 4. Work Completed
The following tasks were performed:

1. Loaded the Breast Cancer Wisconsin dataset.
2. Explored and examined the dataset.
3. Prepared the data for binary classification.
4. Split the dataset into training and testing sets using stratified sampling.
5. Applied feature scaling using StandardScaler.
6. Implemented Logistic Regression.
7. Predicted class labels and class probabilities.
8. Generated a confusion matrix.
9. Evaluated model performance using:
   - Accuracy
   - Precision
   - Recall
   - Specificity
   - F1-Score
   - ROC-AUC Score
10. Compared the model with a majority-class baseline.
11. Compared classification thresholds of 0.3, 0.5 and 0.7.
12. Predicted the class of a new sample.

## 5. Key Results
The Logistic Regression model was evaluated using multiple classification metrics.

The confusion matrix, classification report, ROC curve and threshold comparison were used to understand the model's performance.

Detailed numerical results and visualizations are available in the Jupyter Notebook.

## 6. Conclusion
Logistic Regression was successfully implemented for binary classification using the Breast Cancer Wisconsin dataset.

The model was evaluated using different performance metrics, and the effect of changing classification thresholds was studied.

This activity helped understand binary classification, probability prediction, model evaluation and threshold selection.
